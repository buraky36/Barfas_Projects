BLE Keşif — Cihaz Ekle
----------------------

1 BLE Tarama — Cihazları Listele BLE

Kullanıcı "Cihaz Ekle"ye basar. Mobil Bluetooth taraması başlatır.

Mobil uygulama standart BLE taraması başlatır. Bu aşamada Onloi binary protokolü henüz başlamaz.

// iOS
centralManager.scanForPeripherals(withServices: \[CBUUID(string: "6E400001-B5A3-F393-E0A9-E50E24DCCA9E")\])

// Android
scanner.startScan(listOf(ScanFilter.Builder()
    .setServiceUuid(ParcelUuid.fromString("6E400001-B5A3-F393-E0A9-E50E24DCCA9E"))
    .build()), settings, callback)

2 BLE Bağlantı — GATT Keşfi BLE

Kullanıcı listeden bir cihaz seçer. BLE bağlantısı kurulur. Henüz Onloi frame yok.

Kullanıcı listeden bir cihaz seçer. Mobil BLE bağlantısı kurar ve GATT servisini keşfeder.

// Sırasıyla yapılacaklar:
1. connect(peripheralId)
2. discoverService("6E400001-B5A3-F393-E0A9-E50E24DCCA9E")
3. RX karakteristik: "6E400002-B5A3-F393-E0A9-E50E24DCCA9E"  → Mobil YAZAR (Onloi'ye giden veriler)
4. TX karakteristik: "6E400003-B5A3-F393-E0A9-E50E24DCCA9E"  → Mobil OKUR (notify aç, cihazdan gelen veriler)
5. TX karakteristiğine SUBSCRIBE (notify/indicate enable)

Bağlantı kurulunca bir sonraki adımda Onloi binary protokolü başlar. Frame boyutu 20 byte'ı aşıyorsa 0x00 ayırıcı ile parçalanır.

4 Cihaz Tipi Sorgusu HTTPS

Mobil, deviceCode ile sunucudan cihaz özelliklerini alır. Hangi özelliklerin aktif olduğu (PIN/NFC/FP/QR) buradan gelir — cihazdan değil.

GET https://api.onloi.com/v1/device-types/OK0310

Response 200 OK

{
  "deviceCode": "OK0310",
  "name": "Parmak İzi Okuyucu",
  "capabilities": \[
    "FINGERPRINT",
    "PIN",
    "BATTERY"
  \],
  "ui": {
    "showPin": true,
    "showFingerprint": true,
    "showNfc": false
  }
}

5 Provisioning Token Al HTTPS

Mobil, sunucudan tek kullanımlık token alır. Bu token 5 dakika geçerlidir ve cihaza BLE ile iletilecektir. Kullanıcı kimliği Authorization header'dan alınır; body'de sadece hangi cihazın provision edileceği belirtilir.

POST https://api.onloi.com/v1/devices/provision/start

Request Body

{
  "deviceId": "78356203936"
}

Response 200 OK

{
  "provisioningToken": "<32 byte, base64url>",
  "expiresIn": 300
}

Header: Authorization: Bearer <kullanıcı JWT>
